Read-only weapon identity and ammunition provider
Derived from HD2 HUD+ 0.1.2 by DDRK1NG.
https://www.nexusmods.com/helldivers2/mods/15298

The README bundled with version 0.1.2 expressly permits reuse and modification
with author credit and a link to the Nexus page. That original README is
included unchanged. This is a separate addon, not a re-upload of the HUD.
The original game's boot bytecode and all GUI/HUD rendering are excluded.
Only that version's Lua identity/provider modules and ammunition definitions
are adapted. Later releases are not copied or covered by this permission.

Bingus Shared Loader API and archive format documentation by CowboyBingus:
https://github.com/CowboyBingus/BingusSharedLoader
Requires a separately installed Bingus Shared Loader v15+ (API 1).
This addon does not contain or replace the loader.
