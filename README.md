# HD2 Helper

Windows에서 Helldivers 2의 로드아웃 관리, 스트라타젬 입력, 조준점과 지원 무기 보조 기능을 제공하는 비공식 보조 프로그램입니다.

이 프로젝트는 Arrowhead Game Studios 또는 Sony Interactive Entertainment와 관련이 없습니다.

## 주요 기능

- 로드아웃 프리셋 생성, 복제, 삭제 및 저장
- 갑옷, 주 무기, 보조 무기, 투척 무기와 스트라타젬 자동 선택
- 게임 화면에서 사용하는 프리셋 편집 및 전환 오버레이
- 스트라타젬 슬롯별 단축키와 조합키 입력
- 게임 설정 파일 기반 스트라타젬 키 자동 인식 및 수동 키 지정
- 레이어, 색상, 투명도, 테두리를 조절할 수 있는 조준점 제작기
- 레일건과 에포크용 충전 게이지, 경고음 및 자동 사격 보조
- 게임 내 한글 채팅 입력 보조
- 게임 비활성화 시 오버레이 숨김과 선택적 음소거
- WGC 캡처 환경에서 오버레이 제외 선택 지원

## 설치

1. [Releases](https://github.com/pwj891129-arch/HD2-Helper/releases)에서 사용할 버전의 `HD2.Helper.zip`을 받습니다.
2. ZIP을 새 폴더에 완전히 압축 해제합니다.
3. `HD2 Helper.exe`, `database.json`, `images`, `sounds`를 같은 폴더 구조로 유지합니다.
4. `HD2 Helper.exe`를 실행합니다.

Windows 권한 수준이 게임보다 낮으면 전역 단축키나 입력 전달이 제한될 수 있습니다. 이런 경우 게임과 헬퍼를 같은 권한 수준으로 실행합니다.

## 업데이트와 버전 선택

업데이터는 헬퍼와 별도로 배포됩니다. 업데이터의 `버전 선택`을 누르면 이 저장소의 공개 GitHub Releases를 읽어 다음 조건에 맞는 버전을 표시합니다.

- 초안이 아닌 공개 릴리스
- `2.0.10` 또는 `v2.0.10` 형식의 버전 태그
- 자산 이름이 정확히 `HD2.Helper.zip`인 릴리스

목록은 의미 버전이 높은 순서로 정렬됩니다. 새 릴리스가 현재 설치 버전보다 높으면 `NEW`가 표시되며, 사용자가 버전을 선택한 경우에만 다운로드와 설치가 진행됩니다.

## 사용자 데이터

설정과 프리셋은 설치 폴더와 분리되어 다음 위치에 저장됩니다.

```text
%APPDATA%\HD2 Helper
```

주요 데이터에는 단축키와 프로그램 설정, 로드아웃 프리셋, 제외 항목, 조준점과 지원 무기 설정이 포함됩니다. 같은 Windows 사용자 계정에서는 헬퍼를 다른 폴더에 설치해도 기존 데이터를 계속 사용합니다.

## 자동 선택 참고 사항

- 장비 구성 화면과 게임 UI 언어는 한국어를 기준으로 인식합니다.
- 보유하지 않은 장비와 스트라타젬은 프로그램에서 제외해야 이동 좌표가 게임 목록과 일치합니다.
- UI 배율, 커스텀 폰트, 화면 후처리 또는 입력 지연에 따라 OCR과 자동 선택 정확도가 달라질 수 있습니다.
- 프로그램 설정의 입력 딜레이와 재선택 기능을 환경에 맞게 조절할 수 있습니다.

## 소스 빌드

.NET 8 SDK가 설치된 Windows 환경에서 다음 명령으로 빌드할 수 있습니다.

```powershell
dotnet publish "HD2 Helper.csproj" -c Release
```

실행 파일과 함께 최신 `database.json`, `images`, `sounds`가 필요합니다. 업데이터 소스와 실행 파일은 이 저장소에 포함하지 않습니다.
