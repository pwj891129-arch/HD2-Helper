## 헬다이버즈2 보조 기구
* **업데이터 실행**<br>
`HD2 Helper Updater.exe`를 실행하면 `pwj891129-arch/HD2-Helper`의 GitHub Releases 버전 목록만 확인한 뒤 헬퍼를 같은 창 안에서 실행합니다.<br>
새 릴리스가 있으면 `버전 선택` 왼쪽에 초록색 `NEW`가 표시되며, 각 릴리스에 첨부된 `HD2.Helper.zip` 또는 로컬에 보관된 이전 버전을 직접 선택했을 때만 파일을 교체하고 헬퍼를 재시작합니다.

* **스트라타젬 단축키 자동 인식**<br>게임 설정 파일 `input_settings.config` 기반으로 작동하여 별도의 초기 설정이 필요 없습니다.

* **사후 데이터 관리**<br>업데이트가 중단되어도 `database.json` 수정을 통해 직접 추가할 수 있습니다.

* **패드 지원**<br>`XBOX` / `PS` 외에도 다양한 패드를 지원하여, 단축키 등록이 가능합니다.

* **스트라타젬 & 장비 자동 선택**<br>게임 내 장비구성 메뉴에서 단축키 한 번으로 설정된 항목들을 자동으로 선택합니다.<br>
`텍스트 언어 설정은 한국어만 지원하며, 폰트 변경 모드 사용 시 정상 작동하지 않을 수 있습니다.`<br>
`보유하지 않은 스트라타젬 및 장비는 우클릭으로 제외해야 정상 작동합니다.`

* **프리셋 전환 오버레이**<br>게임 중 단축키로 저장된 프리셋을 작은 이미지 카드로 확인하고 즉시 전환할 수 있습니다.

* **라디얼 오버레이**<br>게임 내 오버레이로 직관적인 스트라타젬 선택이 가능합니다.

* **슬롯별 단축키**<br>각 슬롯에 설정된 스트라타젬을 복잡한 커맨드 없이 단축키 하나로 사용 가능합니다.

* **한글 채팅**<br>별도 오버레이 없이 게임 내 채팅창에서 즉시 한글을 입력합니다.<br>
캐릭터 안 움직이거나 한글 입력 안될 경우 `ESC` / `발사` / `조준` 버튼으로 상태 초기화가 필요합니다.<br>
패드 연결 시에는 한글 채팅 비활성화 됩니다.

## 단축키 기본 설정값
* **자동선택 :** `F1`
* **프리셋 전환 :** `F4`
* **오버레이 :** `마우스 휠 클릭`
* **증원 :** `마우스 버튼1(뒤로 가기)`
* **슬롯 :** `설정 필요`

## 프로그램 특수 조작
* **스트라타젬 & 장비 슬롯**<br>
우클릭 : `선택 해제`

* **스트라타젬 슬롯**<br>
드래그 : `슬롯 변경`

* **선택 목록**<br>
우클릭 : `제외` / `제외 해제`

* **프리셋**<br>
Shift + 우클릭 : `복제`<br>
Ctrl + 우클릭 : `삭제`<br>
더블클릭 : `이름 변경`<br>
드래그 : `순서 변경`<br>

* **프로그램 설정**<br>
단축키 입력 대기 중 우클릭 : `단축키 해제`<br>
프리셋 전환 : `게임 중 F4로 저장된 프리셋 카드 표시`<br>
오버레이 단축키 누름 유지 : `스트라타젬 보기 키 누름 유지`<br>
스트라타젬 입력 조합키 + WASD : `스트라타젬 방향키 입력`<br>
조준점 제작 : `미리보기 창에서 레이어별 조준점 편집`<br>
입력 딜레이 좌클릭 : `+5ms`<br>
입력 딜레이 우클릭 : `-5ms`
